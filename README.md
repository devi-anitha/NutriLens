 Overview
 NutriLens is an AI-powered web-based system designed to enhance nutritional awareness by providing personalized food analysis and intelligent dietary recommendations.
 The system collects user-specific details such as age, gender, weight, and health conditions, and evaluates the nutritional suitability of consumed food items. It processes food input, computes nutrient composition, and delivers           actionable health insights tailored to individual needs.
 NutriLens bridges the gap between food consumption and personalized health guidance through an interactive and user-centric approach.
 Project Components
 1. Backend Server
 Developed using FastAPI
 Handles API requests and business logic
 Processes food inputs and computes nutritional values
 Generates AI-based health insights and recommendations
 Manages user authentication and profile data
 Stores meal history
 2. Frontend Application
 Built using React.js and Vite
 Provides intuitive and responsive UI
 Enables food input and real-time analysis
 Displays nutrient distribution using charts
 Supports profile and history management
3. AI Processing Module
Uses Large Language Models (LLMs)
Generates personalized dietary insights
Evaluates food suitability based on health conditions
Provides intelligent recommendations
4. Database System
Stores user profiles and health data
Maintains meal history
Ensures efficient data handling and retrieval
